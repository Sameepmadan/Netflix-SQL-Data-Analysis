# Netflix SQL Data Analysis

### Exploring Netflix Movies & TV Shows using PostgreSQL

</div>

---

## 📌 Project Overview

This project analyzes Netflix movies and TV shows using SQL and PostgreSQL.

The analysis answers 15 business questions related to content types, ratings, countries, genres, directors, actors, release years, and content categorization.
## Dataset

The dataset contains information about Netflix movies and TV shows, including:

- Show ID
- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## Tools & Technologies

- PostgreSQL
- SQL
- Git
- GitHub

## Business Questions

1. Count Movies vs TV Shows
2. Find the most common rating
3. List movies released in a specific year
4. Find top 5 countries by content
5. Identify the longest movie
6. Find content added in the last 5 years
7. Find content by a specific director
8. Find TV shows with more than 5 seasons
9. Count content by genre
10. Analyze India's content by release year
11. Find documentary movies
12. Find content without a director
13. Find movies featuring Salman Khan
14. Find top 10 actors in Indian content
15. Categorize content based on keywords
